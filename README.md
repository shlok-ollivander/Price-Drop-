# Price-Drop

**Turning food waste into recovered profit.**

Built for InnovaHack Chapter 1 - Round 1 (Online 24-hour Hackathon)

## The Problem

Grocery stores throw away millions of dollars of perfectly good food every day because pricing models haven't changed since the 1970s. Stores operate on razor-thin 1–3% margins, yet perishables sit at full price until the last day—when it's too late—and get a manual 50% sticker slapped on, or go straight to the trash.

## The Solution

Price-Drop is an automated dynamic markdown engine. Instead of a sudden manual price cut, our API continuously calculates an item's shelf life, local demand, and time-to-expiry, and automatically reduces its price over time.

- Shoppers get better discounts.
- Stores recover revenue.
- Food waste is reduced.
